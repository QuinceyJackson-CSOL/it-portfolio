# Audio / Visual Operations

The A/V side of my work: renting and running sound systems for events, and installing and
labeling church sound gear so volunteers can run it. I run this through my own technology
services business, **JacxSon's Essential Solutions LLC** (self-employed) (IT support, A/V rentals and event
sound, and electronics repair).

Why it's in an IT portfolio: A/V is operations work. Inventory, setup procedures, signal
documentation, live troubleshooting under time pressure, and a clean handoff to non-technical
people are the same skills that run a service desk.

## Focus areas
- A/V equipment rentals: portable PA speakers, wireless headset and lavalier mic systems
- Event sound: delivery, load-in, sound check, live playback, on-site Level 1/Level 2 support
- Installs: mixing consoles, wireless mic systems, signal routing and splitting
- Documentation: channel labeling, color-coding, asset inventory, setup procedures
